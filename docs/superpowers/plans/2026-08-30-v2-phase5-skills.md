# v2 Phase 5 — Skills Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Commit policy override:** stays fully uncommitted until the project owner explicitly says to commit. Implementers do **not** run `git commit` or `git add`. Task review diffs are generated by snapshotting target files before dispatch and diffing the snapshot against the post-task file (`diff -u`), not `git diff HEAD`.

**Goal:** Replace Skills' always-visible 2×2 card grid and always-running horizontal marquees with a filterable index — click a category, its capabilities and tech badges expand below.

**Architecture:** One task, one file pair (`SkillsMinimal.jsx`/`.css`), full rewrite. No other file imports either.

**Scope decision made during planning:** the existing `badges` arrays in `skillsData` each list every tool twice (5 real entries duplicated to 10, so the old CSS marquee had enough content to loop seamlessly). The new design has no marquee — badges render once, in a static stagger-in grid on category expand — so this task also deduplicates the data itself, not just the rendering. This is a legitimate part of "replacing the marquee," not scope creep: duplicated data existing only to feed an animation technique this phase removes would be dead weight left behind if not cleaned up.

**Tech Stack:** React 18, `motion/react` (`AnimatePresence`, `useReducedMotion` — both already used elsewhere in this codebase, e.g. `NavRail.jsx`). No automated test suite — verification is `npm run build` plus manual visual confirmation via `npm run dev`.

**Spec:** [docs/DESIGN_SPEC.md](../../DESIGN_SPEC.md) — §19 (Skills redesign).

## Global Constraints

- Only `var(--ink)`, `var(--paper)`, `var(--meta)`, `var(--signal)` colors — no new hardcoded hex/rgba. The existing file has many (`rgba(255,255,255,*)`, `#FFFFFF`) — this is a full rebuild, unlike Part 1's earlier reskin-only pass on this same file, so all of them get replaced this time, not just the header rule.
- Reuse `.section-shell`, `.section-shell-inner`, `.section-label`, `.index-list`, `.index-row`, `.index-row-title`, `.index-row-desc` from `src/styles/section-shell.css` for the category list rows — this unifies Skills with Experience/Case Studies/Contact, which was explicitly the point of this phase per the spec.
- One category expanded at a time (accordion, not a multi-open list) — the first category is expanded by default so the section isn't empty on first render.
- `useReducedMotion()` must gate the expand/collapse and badge-stagger animations, matching the pattern already used in `NavRail.jsx`.
- Real content only: capability text, tool lists, and badge logos/text come from the existing `skillsData`/`globalTechBadges` arrays (deduplicated per the Scope Decision above) — do not invent new skills or drop real ones.

```jsx
function SkillsMinimal() {
  const [activeKey, setActiveKey] = useState(skillsData[0].key)
  const reduceMotion = useReducedMotion()
  const activeCategory = skillsData.find((category) => category.key === activeKey)

  return (
    <section className="skills-minimal-page section-shell" id="skills-minimal">
      <div className="section-shell-inner">
        <h2 className="section-label">Skills</h2>

        <div className="index-list">
          {skillsData.map((category) => (
            <button
              key={category.key}
              type="button"
              className="index-row"
              onClick={() => setActiveKey(category.key)}
              aria-expanded={activeKey === category.key}
            >
              <span className="index-row-title">{category.title}</span>
              <span className="index-row-desc">{category.tools}</span>
            </button>
          ))}
        </div>

        <AnimatePresence mode="wait">
          {activeCategory && (
            <motion.div
              key={activeCategory.key}
              className="skills-detail"
              initial={reduceMotion ? { opacity: 1 } : { opacity: 0, y: 8 }}
              animate={{ opacity: 1, y: 0 }}
              exit={reduceMotion ? { opacity: 1 } : { opacity: 0, y: -8 }}
              transition={{ duration: reduceMotion ? 0 : 0.25, ease: [0.4, 0, 0.2, 1] }}
            >
              <ul className="skills-capabilities">
                {activeCategory.capabilities.map((capability) => (
                  <li key={capability}>{capability}</li>
                ))}
              </ul>

              <div className="skills-badge-grid">
                {activeCategory.badges.map((badge, i) => (
                  <motion.div
                    key={badge.text}
                    className="skill-badge"
                    initial={reduceMotion ? { opacity: 1 } : { opacity: 0, y: 8 }}
                    animate={{ opacity: 1, y: 0 }}
                    transition={{ duration: reduceMotion ? 0 : 0.3, delay: reduceMotion ? 0 : i * 0.05, ease: [0.4, 0, 0.2, 1] }}
                  >
                    <img
                      src={badge.logo}
                      alt={badge.text}
                      className="skill-badge-logo"
                      loading="lazy"
                      decoding="async"
                      width="24"
                      height="24"
                    />
                    <span className="skill-badge-text">{badge.text}</span>
                  </motion.div>
                ))}
              </div>
            </motion.div>
          )}
        </AnimatePresence>
      </div>
    </section>
  )
}

export default memo(SkillsMinimal)
```

Note what changed: `sectionRef`/`isVisible`/the `IntersectionObserver` `useEffect` are gone (they existed to pause/resume the marquee, which no longer exists); `globalTechBadges` and its unused logo imports (`cplusplusLogo`, `davinciLogo`, `gitlabLogo`, `matplotlibLogo`, `seabornLogo`, `pythonLogo`) are removed along with the bottom marquee strip — those tools aren't listed under any of the four real categories above, so there's no "Global Tech" home for them in an index-based (not marquee-based) design; each category's `badges` array is deduplicated from 10 entries (5 real + 5 repeated) down to the 5 real ones.
