# v2 Phase 4 — Full Archive Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Commit policy override:** stays fully uncommitted until the project owner explicitly says to commit. Implementers do **not** run `git commit` or `git add`. Task review diffs are generated by snapshotting each task's target files before dispatch and diffing the snapshot against the post-task file (`diff -u`), not `git diff HEAD`.

**Goal:** Retire the Full Archive's glassmorphic bottom-sheet modal in favor of a real `/archive` route using the same `.index-list` language as the rest of the site.

**Architecture:** Two tasks. Task 1 creates a new, self-contained page (`src/pages/Archive/`). Task 2 wires it into routing, redirects the existing "View full project archive" trigger to navigate there, and deletes the retired `ArchiveOverlay` component.

**Scope decision made during planning:** Archive's `IdentityGlyph` instances (from Phase 3) do **not** receive a `layoutId`. Reasoning: `layoutId` values must be globally unique per concurrently-possible match — Home's Case Study rows already use `glyph-${project.id}` for the Home→Details morph (Phase 3). If Archive rows used the same convention, three different route pairs (Home↔Archive, Home↔Details, Archive↔Details) would all be competing to match against the same ids during whatever transition happens to be active, producing inconsistent partial-morphs for projects that appear on multiple pages simultaneously. Archive's glyphs render as plain, non-shared-layout visuals; the existing Home→Details morph is unaffected. If an Archive→Details morph is wanted later, it needs its own naming scheme (e.g. `archive-glyph-${id}`) as a separate decision, not bundled into this phase.

**Tech Stack:** React 18, React Router (`Route`, `Link`, `useNavigate`), `motion/react` (already a dependency). No automated test suite — verification is `npm run build` plus manual visual confirmation via `npm run dev`.

**Spec:** [docs/DESIGN_SPEC.md](../../DESIGN_SPEC.md) — §17 (Full Archive redesign).

## Global Constraints

- Only `var(--ink)`, `var(--paper)`, `var(--meta)`, `var(--signal)` colors — no new hardcoded hex/rgba. The old `ArchiveOverlay.css`'s nebula gradients, `backdrop-filter` blur, and `rgba(255,255,255,*)` glassmorphism are retired entirely, not carried forward in any form.
- Reuse `IdentityGlyph` from `src/components/IdentityGlyph.jsx` (Phase 3) — do not create a second glyph implementation.
- Reuse `.section-shell`, `.section-shell-inner`, `.section-label`, `.index-list`, `.index-row`, `.index-row-title`, `.index-row-desc` from `src/styles/section-shell.css` (Phase 1's Part-1 predecessor) for the category lists — do not invent parallel classes for the same visual role.
- Categories with zero matching projects must not render an empty section header (preserve the existing `ArchiveOverlay.jsx` behavior of skipping empty categories).
- `ArchiveOverlay.jsx`/`ArchiveOverlay.css` are deleted in this phase, not left as dead code alongside the new page.

- [ ] **Step 1: Create the component**

Create `src/pages/Archive/Archive.jsx`:

```jsx
import { memo, useState } from 'react';
import { Link } from 'react-router-dom';
import './Archive.css';
import IdentityGlyph from '../../components/IdentityGlyph';
import projectsData from '../../data/projects.json';

const CATEGORIES = [
  { id: 'featured', label: 'Featured Systems' },
  { id: 'core', label: 'Core Exploration' },
  { id: 'archived', label: 'Legacy Archives' },
  { id: 'experiment', label: 'Experiments & Labs' },
  { id: 'frontend', label: 'Frontend Engineering' },
];

function Archive() {
  const [previewProject, setPreviewProject] = useState(null);

  return (
    <div className="archive-page section-shell" id="archive">
      <div className="section-shell-inner archive-layout">
        <Link to="/" className="archive-back link-row-item">
          ← Home
        </Link>

        <h1 className="section-label archive-title">Full Archive</h1>

        <div className="archive-columns">
          <div className="archive-lists">
            {CATEGORIES.map((category) => {
              const categoryProjects = projectsData.projects.filter(
                (project) => project.category === category.id
              );
              if (categoryProjects.length === 0) return null;

              return (
                <div key={category.id} className="archive-category">
                  <h2 className="section-label archive-category-label">{category.label}</h2>
                  <div className="index-list">
                    {categoryProjects.map((project) => (
                      <Link
                        key={project.id}
                        to={`/projects/${project.id}`}
                        className="index-row"
                        onMouseEnter={() => setPreviewProject(project)}
                        onFocus={() => setPreviewProject(project)}
                        onMouseLeave={() => setPreviewProject(null)}
                        onBlur={() => setPreviewProject(null)}
                      >
                        <IdentityGlyph projectId={project.id} size={28} className="index-row-glyph" />
                        <span className="index-row-title">{project.title}</span>
                        <span className="index-row-desc">{project.shortDescription}</span>
                      </Link>
                    ))}
                  </div>
                </div>
              );
            })}
          </div>

          <div className="archive-preview-rail" aria-hidden="true">
            {previewProject && (
              <>
                <IdentityGlyph projectId={previewProject.id} size={144} />
                <p className="archive-preview-title">{previewProject.title}</p>
                <p className="archive-preview-desc">{previewProject.shortDescription}</p>
              </>
            )}
          </div>
        </div>
      </div>
    </div>
  );
}

export default memo(Archive);
```

(No `layoutId` prop passed to either `IdentityGlyph` usage — per this plan's Scope Decision above, plain glyphs only. The preview rail is `aria-hidden` since it's a purely decorative echo of information already present in the row being hovered/focused — a screen reader user gets the same title/description directly from the row itself.)
